Toolnook Contracts

A local-first, file-based double-entry accounting CLI for small teams and freelancers. Track income, expenses, and project profitability — no database required.

Features

Double-Entry

Every transaction validated — debits must equal credits

JSON Storage

Human-readable, git-friendly ledger files

Project Tagging

Tag transactions to projects, track per-project profitability

Financial Reports

P&L, Balance Sheet, Cash Flow in terminal tables

CSV Import

Bulk import from spreadsheet exports

Recurring Scheduler

Auto-generate entries for rent, subscriptions, etc.

Quick Start

git clone https://github.com/toolnook/contracts.git
cd contracts
pip install -e .

ledgerlite init
ledgerlite account add Cash asset
ledgerlite account add Revenue revenue
ledgerlite add --description "Client invoice" --debit Cash:1000 --credit Revenue:1000 --tag "acme"
ledgerlite balance
ledgerlite report by-project

Stellar Payment Ledger

A double-entry accounting CLI that reconciles on-chain XLM and asset payments from Stellar Horizon with off-chain bookkeeping. For businesses accepting Stellar payments.

Why it helps Stellar

Horizon Payment Sync

Fetch XLM and asset payments from Horizon and reconcile to double-entry transactions

XLM Amount Handling

Native stroop-to-XLM conversion with Decimal precision

Multi-Asset Tracking

Track XLM, USDC, EURT and custom assets in one ledger

Project Tagging

Tag Stellar payments to projects, report per-project profitability

Financial Reports

P&L, Balance Sheet, Cash Flow with XLM-denominated amounts

Network Support

Sync from public or testnet with passphrase validation

Quick Start

git clone https://github.com/toolnook/contracts.git
cd contracts
pip install -e .

ledgerlite init
ledgerlite account add "Stellar Wallet" asset
ledgerlite account add "XLM Revenue" revenue

# Sync XLM payments from Horizon
ledgerlite stellar sync --account GABC...1234 --network public

ledgerlite balance
ledgerlite report by-project
